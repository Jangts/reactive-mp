# Reactive MP Components 品牌素材

组件库的正式名称为 Reactive MP Components，npm 包名为 @reactive-mp/components。标志使用完整名称；Reactive MP 是母品牌。

## 与 Reactive MP 的关系

母标由两个相同、旋转 180° 的开放回钩组成。两个构件咬合但不接触，接合处始终保留连续留白，单色时也能分出两个单元。曲线使用少量几何贝塞尔段描述，避免描摹位图边缘的抖动。

组件库标志沿用母标的轮廓、对称与两种青绿色，在每条连接臂再留一道约 4 单位的间隔，形成四个可独立组合的模块。不能用连接桥填平母标的白缝。

字标完整沿用 Reactive MP 母品牌的字形，主行保留 Reactive MP，次行以主青色写 Components。SVG 字标已转为路径，不依赖消费工程安装字体。
