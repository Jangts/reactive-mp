# 组件总览

按任务选择组件。每页提供完整原生示例、属性、事件、插槽、方法与使用边界。

| 组件 | 用途 |
| --- | --- |
| [Form 表单](form.md) | 管理模型、字段注册、校验与提交快照。 |
| [FormItem 表单项](form-item.md) | 连接命名字段与 Form，承载标签、帮助和校验反馈。 |
| [FormButton 表单按钮](form-button.md) | 根据最近 Form 的待处理与禁用状态提交或重置。 |
| [Input 输入框](input.md) | 使用原生键盘和焦点事件编辑单行文本。 |
| [Textarea 多行输入](textarea.md) | 支持自动高度和可选字数统计的长文本输入。 |
| [Checkbox 复选框](checkbox.md) | 表示布尔选择，false 也是有效值。 |
| [Switch 开关](switch.md) | 通过原生开关切换布尔设置。 |
| [RadioGroup 单选组](radio-group.md) | 从可见选项中选择一个标量值。 |
| [CheckboxGroup 复选组](checkbox-group.md) | 选择由选项值组成的数组。 |
| [Select 选择器](select.md) | 通过原生 picker 或确认弹窗选择映射后的选项值。 |
| [ColumnPicker 多列选择器](column-picker.md) | 返回各个独立列选中的值。 |
| [DatePicker 日期时间选择器](date-picker.md) | 通过原生 picker 选择日期或时间。 |
| [RegionPicker 地区选择器](region-picker.md) | 选择原生行政地区，并保留原生 change 元数据。 |
| [Cascader 级联选择器](cascader.md) | 选择树形路径，可由外部按需加载子节点。 |
| [Calendar 日历](calendar.md) | 在内嵌月视图中选择 YYYY-MM-DD 日期。 |
| [Upload 文件上传](upload.md) | 选择图片或视频，通过应用适配器协调上传任务。 |
| [Video 视频](video.md) | 围绕原生 video 协调播放意图、可见性、进度和声音。 |
| [VideoGroup 视频声音分组](video-group.md) | 协调后代视频参与者的声音，不规定版式。 |
| [Swiper 轮播](swiper.md) | 协调索引、原生切换、稳定内容身份和可选轮播版式。 |
| [ImageItem 图片内容项](image-item.md) | 为 Swiper 渲染图片内容，不控制轮播版式。 |
| [MediaItem 媒体内容项](media-item.md) | 适配图片和视频内容，并携带事件类型转发视频事件。 |
| [MediaSwiper 媒体轮播](media-swiper.md) | 组合轮播、混合媒体、激活项播放和声音协调。 |
