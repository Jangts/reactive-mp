# Component catalog

Select a component to see its complete native example, properties, events, slots and methods.

| Component | Use |
| --- | --- |
| [Form](form.md) | Manage a model, field registration, validation and submit snapshots. |
| [FormItem](form-item.md) | Connect a named field to Form and render its label, help and validation feedback. |
| [FormButton](form-button.md) | Submit or reset the nearest Form using its current pending and disabled state. |
| [Input](input.md) | Edit a single-line string with native keyboard and focus events. |
| [Textarea](textarea.md) | Edit longer text with automatic height and an optional character counter. |
| [Checkbox](checkbox.md) | Represent a Boolean choice, including a valid false value. |
| [Switch](switch.md) | Toggle a Boolean setting through a native switch. |
| [RadioGroup](radio-group.md) | Choose one scalar value from visible options. |
| [CheckboxGroup](checkbox-group.md) | Choose an ordered array of option values. |
| [Select](select.md) | Choose mapped option values with a native picker or a confirmation popup. |
| [ColumnPicker](column-picker.md) | Return one selected value from each independent column. |
| [DatePicker](date-picker.md) | Select a date or time through the native picker. |
| [RegionPicker](region-picker.md) | Select native administrative regions and retain native change metadata. |
| [Cascader](cascader.md) | Select a path in a tree, with optional external child loading. |
| [Calendar](calendar.md) | Choose a YYYY-MM-DD date in an inline month grid. |
| [Upload](upload.md) | Select image/video files and coordinate upload tasks through an application adapter. |
| [Video](video.md) | Coordinate playback intent, visibility, progress and sound around native video. |
| [VideoGroup](video-group.md) | Coordinate audible playback among descendant video participants without imposing a layout. |
| [Swiper](swiper.md) | Coordinate index, native transitions, stable item identity and optional carousel layouts. |
| [ImageItem](image-item.md) | Render an image item for Swiper without controlling the carousel layout. |
| [MediaItem](media-item.md) | Adapt image/video items and forward video events with their event type. |
| [MediaSwiper](media-swiper.md) | Compose Swiper with mixed media, active-item playback and sound coordination. |
