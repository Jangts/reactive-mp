# Reactive MP Components

Headless interaction capabilities for native WeChat Mini Programs. Reuse behavior, hooks and native wiring while the application owns structure, layout and visual identity. Ordinary Pages can use wrappers; reactive pages can compose hooks directly.

## Start with a task

| Task | Components |
| --- | --- |
| Collect and validate data | [Form](form.md), [FormItem](form-item.md), [FormButton](form-button.md) |
| Text and Boolean input | [Input](input.md), [Textarea](textarea.md), [Checkbox](checkbox.md), [Switch](switch.md) |
| Lists, wheels and dates | [Select](select.md), [Cascader](cascader.md), [Calendar](calendar.md) |
| File task ownership | [Upload](upload.md) |
| Playback and sound coordination | [Video](video.md), [VideoGroup](video-group.md) |
| Images, cards and mixed-media carousels | [Swiper](swiper.md), [MediaSwiper](media-swiper.md) |

The [catalog](catalog.md) lists every wrapper. [Quick start](getting-started.md) starts with a complete native page. [Hooks and controllers](hooks.md) explains custom structure.

Logic entries do not register components, start native work or load styles. Optional wrappers include base structure and styling. For a fully custom appearance, combine hooks with native nodes.
