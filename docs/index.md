# Reactive MP

- [响应式与组合逻辑](guide.md)：状态、派生值、监听、生命周期和资源释放。
- [原生配置与动态声明](native-options.md)：两种写法可以混合使用。
- [共享状态](store.md)：惰性 Store 与跨页面共享。
- [API 参考](api.md)：公开接口和类型签名。
- [运行原理](setup-runtime.md)：想深入理解时再读。
